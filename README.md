1.CommonLib
  -PRIMXCS Agent 프로그램에서 사용하고 있는 라이브러리 모음
  -OpenSSL, OpenSSL_Static : SSL 통신을 위한 라이브러리
  -SQLite : SQLite DB 라이브러리
  -Utils : ARIA, IPC등 여러 가지 기능을 가지고 있는 라이브러리
  -ZedAPI : ZED 파일 사용을 위한 PRIMX 제공 API 라이브러리
  -ZedDecryptAPI : ZED 파일을 복호화 하는 API 라이브러리
2.PRIMXAgent
  -PRIMXCS Agent 시스템 모드 프로그램
3.PRIMXAgentCS
  -PRIMXCS Agent 사용자 모드 프로그램 (UI 포함되어 있음)
4.PRIMXDecryptFile
  -이동파일에 포함되는 File Decrypt 해주는 프로그램 (이동파일 실행 프로그램임)
5.PRIMXEncMonitor
  -정책에 의해 지정된 폴더를 모니터링하여 SafetZone에서 복사/이동된 파일인 경우 삭제하는 프로그램
  -ZONECENTRAL P354 정책 적용으로 현재는 사용하지 않음
6.PRIMXUninstall
  -PRIMX 프로그램을 Uninstall하는 프로그램
